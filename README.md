Based on the programs currently in this repository:

- **Basic Input and Output** — using `cin` and `cout`
- **Variables and Data Types** — `int`, `float`, and `char`
- **Arithmetic Operations** — calculations using operators and formulas
- **Conditional Statements** — `if`, `if-else`, and `switch`
- **Swapping Values** — with and without a temporary variable
- **Escape Characters** — printing quotes and backslashes
- **Basic Problem Solving** — area of a triangle, distance around a circular track, and a simple grading system
- **Naming Practices** — using descriptive variable names and camelCase

## How to Run

1. Install a C++ compiler such as **GCC**.
2. Clone this repository:

   ```bash
   git clone https://github.com/amjadali04/cpp_repo.git
   ```

3. Open the project folder in VS Code or your preferred editor.
4. Compile a program:

   ```bash
   g++ filename.cpp -o program
   ```

5. Run it:

   **Windows**
   ```bash
   .\program.exe
   ```

   **Linux / macOS**
   ```bash
   ./program
   ```

Replace `filename.cpp` with the name of the file you want to run. Each source file has its own `main()` function, so compile and run programs individually.

> Note: Some early exercises use `conio.h` and `getch()`, which are not part of standard C++. If your compiler does not support them, remove those lines before compiling.
